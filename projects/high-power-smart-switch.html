Overview

The CoolSWITCH is a wireless high-power smart switch designed for Industry 4.0 applications. It functions as a wireless solid-state relay with integrated current sensing, PWM control, soft start/stop, and comprehensive safety features. The device is built around Infineon's 600V CoolMOS™ C7 Gold MOSFETs and an ESP8266 microcontroller.

What Problem Does It Solve?

Industry 4.0 requires smart equipment that can communicate, self-monitor, and predict failures. Traditional mechanical relays have moving parts that wear out, lack communication capabilities, and cannot provide real-time operational data. The CoolSWITCH addresses these limitations by offering a solid-state, wirelessly controllable switch that continuously monitors current consumption and can be integrated into predictive maintenance systems.

Key Features

  • Wide Voltage Range Operates from 12–300 VDC and 87–230 VAC, making it suitable for both low-voltage DC and mains AC applications.
  • High Current Capacity Supports up to 50A (DC/AC) with low ON-state resistance comparable to mechanical relays.
  • Wireless Control Built-in WiFi (ESP8266) with HTTP/REST API and MQTT support for remote control and monitoring.
  • Current Sensing Integrated Infineon TLI4970 current sensor provides real-time load current measurement for monitoring and predictive maintenance.
  • PWM Capability Supports speed and power control via pulse-width modulation.
  • Safety Features Automatic over-current detection and shutdown, secure communication, and fail-safe operation.
  • Soft Start/Stop Gradual switching to prevent inrush current and voltage spikes.
  • Compact Design PCB footprint of approximately 70×50mm with modular power supply options.

Firmware & Software

The CoolSWITCH runs on the ESP8266 and is programmed in Arduino C++. It exposes a secure HTTP/REST API and publishes data via MQTT.

HTTP/REST API

GET /
→ Hello message with device name
POST /turnOn
→ Turn switch ON
POST /turnOff
→ Turn switch OFF
GET /state
→ Current state (0-4)
GET /current
→ Load current (Amps)
POST /setValue
→ Configure WiFi, MQTT, limits

MQTT Integration

Published Topics:
CoolSWITCH-XXXXXXXXX/state → Current switch state
CoolSWITCH-XXXXXXXXX/current → Current consumption (Amps)

Security

HTTP endpoints are secured with Diffie-Hellman key exchange (Curve25519) and HMAC-SHA256 authentication. Sequence numbers prevent replay attacks.

Code Example

Below is a minimal example showing how to control the CoolSWITCH using Python requests. 

# Python client example for CoolSWITCH
import requests
import hmac
import hashlib
import time

class CoolSwitch:
    def __init__(self, host, shared_secret):
        self.host = host
        self.secret = shared_secret
        self.seq_nr = 0

    def _sign_request(self, uri):
        self.seq_nr += 1
        nonce = str(int(time.time() * 1000))
        message = f"{uri}?seqNr={self.seq_nr}&nonce={nonce}"
        signature = hmac.new(
            self.secret.encode(),
            message.encode(),
            hashlib.sha256
        ).hexdigest()
        return f"{message}&hmac={signature}"

    def turn_on(self):
        uri = "/turnOn"
        url = f"http://{self.host}{self._sign_request(uri)}"
        return requests.post(url)

    def turn_off(self):
        uri = "/turnOff"
        url = f"http://{self.host}{self._sign_request(uri)}"
        return requests.post(url)

    def get_state(self):
        url = f"http://{self.host}/state"
        return requests.get(url).json()

# Usage example
switch = CoolSwitch("CoolSWITCH-4548297.local", "your_shared_secret")
switch.turn_on()
print(switch.get_state())  # {'state': 1}

Development Journey

01

Concept & Requirements

Identified the need for a wireless solid-state relay with current sensing for Industry 4.0 applications. Defined voltage/current ranges and feature set.

02

Schematic Design

Designed the circuit in KiCad, selecting the CoolMOS™ C7 MOSFETs, 1EDI gate driver, TLI4970 current sensor, and ESP8266 MCU.

03

PCB Layout & Manufacturing

Laid out the 70×50mm 4-layer PCB with 2oz copper. Manufactured by PCBWay with black silkscreen finish.

04

Assembly & Testing

Assembled the boards and performed smoke tests. Verified WiFi connectivity, current sensing accuracy, and switching capability on both DC and AC loads.

05

Firmware Development

Developed the Arduino C++ firmware with HTTP/REST API, MQTT publishing, security (Diffie-Hellman + HMAC), and state machine control.

06

Open Source Release

Released all hardware design files (KiCad), firmware source code, and Python client libraries under the MIT License.
